# Security Policy

Zenith remains pre-1.0. Production use is supported only inside the operating envelope in the README. Anyone admitted by Horizon's `viewHorizon` Gate can use every mutation this interface exposes.

Please do not open public issues for suspected vulnerabilities. Report them privately through [GitHub's security advisory form](https://github.com/devaction-labs/zenith/security/advisories/new) and include the affected version, impact, reproduction steps, and any suggested mitigation.

Security reports will be acknowledged as soon as practical. Until a fix is available, avoid publishing details that could put users at risk.
